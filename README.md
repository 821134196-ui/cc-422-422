# 演艺场馆无线麦克风电池周转与充电系统

管理麦克风、腰包、电池、充电槽、演出场次、领用清单、归还检测与故障隔离的一体化系统。
零外部依赖，仅使用 Node.js 22 内置的 `node:sqlite` 与 HTTP 模块。

## 单条命令启动

```bash
npm start          # 等价于 node --no-warnings src/server.js
# 打开 http://localhost:3000
```

首次启动若数据库为空，会**自动创建演出前后周转样例**（5 个场次、6 支麦克风、5 个腰包、
11 块电池、2 个充电柜 14 槽），无需任何额外步骤。重置演示数据：删除 `data/app.db` 后重启，
或运行 `npm run demo`。

环境变量：`PORT`（默认 3000）、`DB_FILE`、`TICK_MS`（进程任务节拍，默认 5000ms）。

## 核心业务规则

- **套装唯一**：`equipment_locks` 对设备类型+设备 ID 加 UNIQUE 约束，同一电池（及麦克风/
  腰包）不可能同时出现在两份未结清清单；服务端加件前置校验 + 锁定时最终防线双保险。
- **领用后锁定**：草稿可编辑，锁定后设备置为占用且套装不可改，发出后进入归还窗口。
- **充电回执乱序**：每条回执带槽位单调 `seq`，`seq ≤ 已应用最大值` 的旧包标记丢弃
  （`applied=2`），绝不覆盖较新电量；会话结束后的迟到回执不会复活会话。
- **低电量（<20%）**：归还时与在库巡检都会进故障队列，入槽充电不受限。
- **充电失败 / 接触不良**：适配器回执结束会话、电池回库、故障进队，槽位保留结果留档。
- **健康度（SOH <80%）自动隔离**：充满按循环次数衰减（PRO 0.25%/次，LITE 0.5%/次），
  跌破即自动隔离。人工解除须**另一位**库房管理员复核；SOH 仍不达标时复核备注必须包含
  “降级使用”，放行后不再被自动巡检重复隔离。
- **归还漏件**：完成清点时每件未归还设备生成 `missing_return` 故障，可“确认丢失”
  （设备置 lost，不可再排期）。
- **迟到回传不覆盖清点**：清单一旦 `settled`，之后扫描只写 `return_scans(accepted=0)`，
  缺件状态与设备状态均不改变。
- **错频**：按频段 ±4MHz 协调窗口判定，超窗报错、可一键校正并关闭故障。

## 进程内任务

每 `TICK_MS` 一拍：推进所有充电中会话一档电量并产生回执 → 应用乱序安全的回执队列 →
低电量巡检 → 健康度隔离巡检 → 生成一次性提醒（`POST /api/tasks/tick` 可手动触发，
`GET /api/alerts` 读取）。

## 本地充电适配器

`src/adapter.js` 模拟硬件：`planCharge()` 生成 plugged/progress/full 回执序列，
支持 `fail`（充电失败）、`contactBadAt`（接触不良）、`shuffle`（倒序乱序投递）、
`deliverLate()`（迟到回传），全部进入与真实设备一致的入库→应用管道。

## 测试

```bash
npm test     # 27 个用例（node:test，内存 SQLite）
```

覆盖需求指定的五类场景：

1. **套装唯一** — 跨清单争用加件/锁定双拦截、结算释放后可复用、隔离电池禁入
2. **充电回执乱序** — seq 保序、跨拍旧包丢弃、失败/接触不良、会话结束后迟到回执
3. **低电量与健康隔离** — 故障生成、充满跌破自动隔离、双人复核/降级使用/驳回
4. **漏件处理** — 逐件建故障、清点后迟到回传拒收不覆盖、丢失不可再排期、错频窗口
5. **岗位权限** — 四岗位动作边界、未登录拒绝、套装状态流转非法操作
