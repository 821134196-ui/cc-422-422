# 声场周转台 · 演艺场馆无线麦克风电池周转与充电系统

管理无线麦克风、腰包、电池、充电槽、演出场次、领用清单、归还检测与故障隔离。
零第三方依赖：Node.js ≥ 22 内置 `node:sqlite` + 原生 HTTP + 原生前端。

## 一条命令启动（演示）

```bash
npm run demo
# → http://localhost:8080
```

自动重建 SQLite 演示数据并启动，内置三场前后周转样例：

| 场次 | 状态 | 样例看点 |
|---|---|---|
| 《夜莺与玫瑰·原创音乐剧》今晚 19:30 | 待演出 | 两张领用单已锁定（主持人/女主角），一张草稿；MH-07 错频 |
| 《声临阿莱城·沉浸声音剧场》 | 演出中 | 套装电池每 6 秒放电，低电量自动进故障队列 |
| 《仲夏夜合唱节闭幕场》昨晚 | 已结清 | 腰包丢失走例外结算；清点后迟到回传挂起不覆盖；BT-11 隔离待经理复核 |

`npm start` 仅在数据库为空时播种；`npm run demo` 总是重置为演示状态。
端口可用 `PORT=8090 npm run demo` 调整。

## 六个页面

1. **场次日历** — 月历 + 场次一览，待演/演出中/已结清分色
2. **设备套装** — 按演出分组；草稿可加设备，锁定后写入占用；含麦克风频率台账（撞频自动故障）
3. **充电柜** — A/B 柜槽位网格，电量条 + 健康度 + 最新回执；可放入/取下电池、模拟充电失败/接触不良/乱序两帧
4. **领用清单** — 新建草稿、统计与跳转归还
5. **归还检测** — 麦克风 / 电池 / 腰包三列，缺件红底；逐条填丢失说明才能结算
6. **故障队列** — 低电量、充电失败、接触不良、丢失、错频、漏件、健康隔离、迟到回传；审计日志

右上角切换演示岗位（周砚秋经理 / 韩听澜舞台主管 / 沈既明调音师 / 陆知遥设备员），
无权限的按钮置灰，服务端同样强校验。

## 核心规则

- **套装唯一**：`holds(kind, ref_id)` 主键保证同一物理设备只能被一张生效清单占用；锁单冲突整体回滚。
- **锁定**：仅舞台主管/经理；至少含一支麦克风；隔离电池/故障设备禁入。
- **乱序回执**：每槽维护单调 `last_seq`，回执 seq 不更新即丢弃（`receipt_events.applied=0` 留痕），电量绝不回退。
- **健康隔离**：回执健康度 < 80% 自动隔离并进故障队列；解除须 **设备员申请 → 经理复核**，
  且复核时健康度仍低于阈值则系统拒绝批准。
- **漏件处理**：结算时缺件必须逐条登记例外（按丢失处理）；未登记则中止结算并产生 `missing_return` 故障。
- **迟到回传**：场次清点（`checked_in`）后到达的归还回传仅挂起（`return_scans.applied=0`），不改动归还状态与清点结论。
- **岗位权限**：调音师改频、设备员管柜/申请解除、舞台主管锁单/结算、经理复核/销案（职责分离）。

## 代码结构

```
src/db.js       建表与常量（健康阈值 80 / 低电 20）
src/domain.js   领域服务：权限、套装锁定、回执乱序、隔离复核、归还结算、故障
src/charger.js  本地充电柜适配器（模拟硬件回执，含乱序帧注入）
src/tasks.js    进程内任务：充电推进、演出放电、低电告警、开演前提醒
src/seed.js     演示数据（演出名/人员均为虚构演示资料）
src/queries.js  前端聚合只读视图
src/server.js   HTTP API + 静态页
src/demo.js     单条启动入口
public/         六个页面（象牙白 #F7F3EA / 深紫灰 #2B2640 / 亮青 #12D3CF）
test/           node:test，18 个用例
```

健康度自动隔离与双人复核（低于阈值禁止批准、驳回）、漏件拦截与例外结算、迟到回传不覆盖、
岗位权限矩阵与撞频自动销案。
